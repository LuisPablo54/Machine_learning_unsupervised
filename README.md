## Temario

### Primer parcial — Fundamentos de redes neuronales

| Tema | Subtemas |
|------|----------|
| **1. Conceptos básicos** | Gradiente estocástico y variantes · Optimización · Introducción al deep learning · Deep learning vs. ML clásico · Impacto de las redes neuronales |
| **2. El perceptrón** | Regresión logística y el perceptrón · Perceptrón multicapa (MLP) · Retropropagación · Implementación en librería de enlace dinámico |

**Temas cubiertos en [`ML2_P1_Resumen.ipynb`](./parcial_1/ML2_P1_Resumen.ipynb):**
- La neurona artificial: suma ponderada, bias, pesos
- Funciones de activación: escalón, sigmoidal, ReLU, Softmax
- Problema de Simetría e inicialización de pesos (Xavier / He)
- Backpropagation: forward pass, backward pass, regla de la cadena
- Ejemplo numérico de forward pass (red 4→3→1)
- Ejercicios tipo examen resueltos con código
- Implementación completa en Keras sobre MNIST
